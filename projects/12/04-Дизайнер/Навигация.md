# Навигация

Навигация RoomBook описана диаграммами состояний (state machine): состояние — экран или модальное окно, переход — действие пользователя (кнопка, вкладка) или результат проверки системой (в квадратных скобках).
Номера экранов (Э-01…Э-09) совпадают с документом [Пользовательский интерфейс](Пользовательский%20интерфейс.md), номера вариантов использования — с [Варианты использования](../03-Системный%20аналитик/Варианты%20использования.md).

## 1. Карта экранов

| № | Экран | Роль | UC |
|---|---|---|---|
| Э-01 | Вход | все | UC-01 |
| Э-02 | Поиск свободной аудитории | Студент, Преподаватель | UC-03 |
| Э-03 | Календарь занятости аудитории | все | UC-02 |
| Э-04 | Форма бронирования (модальное окно) | Студент, Преподаватель | UC-04 |
| Э-05 | Мои бронирования | Студент, Преподаватель | UC-05, UC-06, UC-07 |
| Э-06 | Уведомления | все | UC-12 |
| Э-07 | Очередь заявок | Диспетчер | UC-08 |
| Э-08 | Аудиторный фонд | Диспетчер | UC-09 |
| Э-09 | Импорт расписания и конфликты | Диспетчер | UC-10, UC-11 |

Общие элементы всех экранов после входа: шапка с логотипом (ведёт на стартовый экран роли), вкладки разделов, колокольчик уведомлений со счётчиком непрочитанных, имя и роль пользователя, кнопка «Выйти».

## 2. Интерфейс в целом

Диаграмма не имеет конечного состояния: это веб-приложение, между разделами можно переключаться сколько угодно. Выход из системы возвращает на экран входа.

```mermaid
stateDiagram-v2
    [*] --> Вход
    Вход --> ГлавнаяСтудентаПреподавателя : [роль = Студент или Преподаватель]
    Вход --> ГлавнаяДиспетчера : [роль = Диспетчер]
    ГлавнаяСтудентаПреподавателя --> Вход : кнопка «Выйти»
    ГлавнаяДиспетчера --> Вход : кнопка «Выйти»

    state "Главная страница (Студент / Преподаватель)" as ГлавнаяСтудентаПреподавателя
    state "Главная страница (Диспетчер)" as ГлавнаяДиспетчера
    state "Э-01 Вход" as Вход

    note right of Вход
        Гостевая страница: форма входа.
        Регистрации нет — учётные записи
        университетские.
    end note
```

## 3. Э-01. Вход

```mermaid
stateDiagram-v2
    state "Форма входа (почта + пароль)" as Форма
    state "Окно ошибки «Неверная почта или пароль»" as Ошибка
    state "Сообщение «Вход только для адресов университета»" as Домен
    state "Сообщение «Учётная запись отключена»" as Отключена
    state проверка <<choice>>

    [*] --> Форма
    Форма --> проверка : кнопка «Войти»
    проверка --> Ошибка : [данные неверны]
    проверка --> Домен : [чужой домен]
    проверка --> Отключена : [учётная запись деактивирована]
    проверка --> [*] : [данные верны] → главная страница роли
    Ошибка --> Форма : кнопка «Понятно»
    Домен --> Форма
    Отключена --> Форма
```

## 4. Главная страница — Студент / Преподаватель

Вкладки в шапке: **Поиск аудиторий** (стартовая) и **Мои бронирования**; колокольчик открывает **Уведомления**.

```mermaid
stateDiagram-v2
    state "Э-02 Поиск аудиторий" as Поиск
    state "Э-05 Мои бронирования" as Мои
    state "Э-06 Уведомления" as Увед
    state вкладка <<choice>>

    [*] --> вкладка
    вкладка --> Поиск : вкладка «Поиск аудиторий» (по умолчанию)
    вкладка --> Мои : вкладка «Мои бронирования»
    вкладка --> Увед : колокольчик
    Поиск --> вкладка
    Мои --> вкладка
    Увед --> вкладка
```

### 4.1. Поиск и бронирование (Э-02 → Э-03 → Э-04)

```mermaid
stateDiagram-v2
    state "Э-02 Поиск: фильтры + список аудиторий" as Поиск
    state "Пустой результат «Свободных аудиторий нет»" as Пусто
    state "Э-03 Календарь аудитории (неделя / день)" as Календарь
    state "Э-04 Форма бронирования" as Форма
    state "Э-04а Ошибка у поля «Число участников»" as Ошибка
    state "Э-04б Окно «Время уже занято»" as Конфликт
    state "Э-04в «Заявка отправлена» (статус: На рассмотрении)" as Отправлена
    state "Э-04г «Аудитория забронирована» (статус: Подтверждено)" as Подтверждено
    state результат <<choice>>
    state проверка <<choice>>
    state роль <<choice>>

    [*] --> Поиск
    Поиск --> результат : кнопка «Найти»
    результат --> Поиск : [есть свободные]
    результат --> Пусто : [нет свободных]
    Пусто --> Поиск : изменить фильтры

    Поиск --> Календарь : кнопка «Календарь» у аудитории
    Календарь --> Поиск : «← К результатам поиска»
    Календарь --> Календарь : «← Неделя» / «Неделя →» / «День»

    Поиск --> Форма : кнопка «Забронировать» у аудитории
    Календарь --> Форма : клик по свободному слоту / «Забронировать»

    Форма --> проверка : «Отправить заявку» / «Забронировать»
    проверка --> Ошибка : [участников больше вместимости]
    Ошибка --> Форма : исправить число
    проверка --> Конфликт : [слот занят, пока заполнялась форма]
    Конфликт --> Поиск : «К поиску аудиторий»
    Конфликт --> Календарь : «Выбрать другое время»
    проверка --> роль : [данные корректны]
    роль --> Отправлена : [Студент]
    роль --> Подтверждено : [Преподаватель]
    Отправлена --> [*] : «Мои бронирования» / «Закрыть»
    Подтверждено --> [*] : «Мои бронирования» / «Закрыть»
    Форма --> Календарь : «Отмена» / «×»
```

### 4.2. Мои бронирования (Э-05)

```mermaid
stateDiagram-v2
    state "Э-05 Список бронирований + фильтр по статусу" as Список
    state "Э-05а Подтверждение отмены" as Отмена
    state "Э-05б Перенос: новая дата и время" as Перенос
    state "Сообщение о конфликте под полями" as Занято
    state "Э-04 Форма бронирования (заполнена)" as Форма
    state проверка <<choice>>

    [*] --> Список
    Список --> Список : вкладка-фильтр статуса
    Список --> Отмена : кнопка «Отменить» [бронь ещё не началась]
    Отмена --> Список : «Отменить бронирование» → статус «Отменено»
    Отмена --> Список : «Не отменять»

    Список --> Перенос : кнопка «Перенести» [бронь ещё не началась]
    Перенос --> проверка : кнопка «Перенести»
    проверка --> Занято : [новый слот занят]
    Занято --> Перенос : выбрать другое время
    проверка --> Список : [слот свободен] → у студента «На рассмотрении», у преподавателя «Подтверждено»
    Перенос --> Список : «Отмена»

    Список --> Форма : «Подать заново» (отклонено) / «Повторить» (завершено)
    Список --> [*] : «+ Новое бронирование» → Э-02
```

### 4.3. Уведомления (Э-06)

```mermaid
stateDiagram-v2
    state "Э-06 Список уведомлений (непрочитанные выделены)" as Список
    state "Э-05 Мои бронирования" as Мои
    state "Э-04 Форма бронирования" as Форма
    state "Э-02 Поиск" as Поиск

    [*] --> Список : колокольчик
    Список --> Список : «Отметить все прочитанными»
    Список --> Мои : «Открыть бронирование» (подтверждено)
    Список --> Форма : «Подать заявку заново» (отклонено)
    Список --> Поиск : «Найти аудиторию» (отменено диспетчером)
```

    state "Э-09 Расписание" as Расписание
    state вкладка <<choice>>

    [*] --> вкладка
    вкладка --> Заявки : вкладка «Заявки» (по умолчанию)

    вкладка --> Аудитории : вкладка «Аудитории»
    вкладка --> Расписание : вкладка «Расписание»

### 5.1. Заявки (Э-07)

```mermaid
stateDiagram-v2
    state "Э-07 Очередь заявок «На рассмотрении»" as Очередь
    state "Э-07а Отклонение: ввод причины" as Отклонение

    state проверка <<choice>>

    [*] --> Очередь
    Очередь --> Очередь : сортировка «По дате подачи» / «По дате бронирования», фильтр корпуса
    Очередь --> проверка : кнопка «Подтвердить»
    проверка --> Очередь : [слот свободен] → «Подтверждено», уведомление автору
    проверка --> Конфликт : [слот уже занят]
    Конфликт --> Отклонение : «Отклонить с причиной»
    Конфликт --> Очередь : «Закрыть»
    Очередь --> Отклонение : кнопка «Отклонить»
    Отклонение --> Очередь : «Отклонить заявку» [причина указана] → «Отклонено», уведомление автору

```

### 5.3. Импорт расписания (Э-09)

```mermaid
stateDiagram-v2
    state "Шаг 1. Выбор файла и периода" as Файл
    state "Шаг 2. Итог проверки: загружено / ошибки" as Проверка
    state "Шаг 3. Список конфликтов" as Конфликты
    state "Э-09а Отмена брони: ввод причины" as Отмена
    state "Шаг 4. «Импорт завершён»" as Готово
    state "Ошибка «Неверный формат файла»" as Формат
    state разбор <<choice>>
    state есть_конфликты <<choice>>

    [*] --> Файл
    Файл --> разбор : «Загрузить и проверить»
    разбор --> Формат : [не CSV/XLSX]
    Формат --> Файл
    разбор --> Проверка : [файл разобран]
    Проверка --> Файл : загрузить исправленный файл
    Проверка --> есть_конфликты : подтвердить загрузку корректных строк
    есть_конфликты --> Готово : [конфликтов нет]
    есть_конфликты --> Конфликты : [есть конфликты]
    Конфликты --> Отмена : «Отменить бронь»
    Отмена --> Конфликты : «Отменить бронирование» [причина указана] → уведомление автору
    Конфликты --> Конфликты : «Попросить перенести» → уведомление автору
    Конфликты --> Готово : [все конфликты разобраны]
    Готово --> [*]
```

## 6. Правила навигации

- Модальные окна (Э-04, Э-05а/б, Э-07а/б, Э-08а/б, Э-09а) открываются поверх текущего экрана; закрываются кнопкой «Отмена», «×» или клавишей Esc — пользователь остаётся на том же экране.
- Действия, которые нельзя вернуть (отмена бронирования, отклонение заявки), всегда требуют подтверждения в модальном окне.
- После успешного действия пользователь остаётся в том же разделе, список обновляется, показывается короткое сообщение об успехе.
- Кнопки «Отменить» и «Перенести» не показываются у бронирований, время начала которых наступило (UC-06, исключение).
- Прямой переход по адресу на экран чужой роли (например, студент открывает «Заявки») возвращает на стартовый экран своей роли (NFR-10).
