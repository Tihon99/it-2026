# Компоненты пользовательского интерфейса

Набор повторяющихся элементов, из которых собраны все экраны RoomBook. Реализация — в [Верстка/css/style.css](Верстка/css/style.css), примеры использования — в HTML-страницах папки [Верстка](Верстка/).

## 1. Стилевая основа

### Цвета

| Назначение | Переменная CSS | Значение | Где используется |
|---|---|---|---|
| Основной (акцент) | `--primary` | `#2563eb` | главные кнопки, активная вкладка, выбранный слот |
| Текст | `--text` | `#1f2937` | основной текст |
| Второстепенный текст | `--text-muted` | `#6b7280` | подписи, даты, подсказки |
| Фон страницы | `--bg` | `#f5f7fb` | фон под карточками |
| Рамки | `--border` | `#e5e7eb` | карточки, поля, таблицы |
| Успех | `--success` | `#16a34a` | «Подтверждено», «Подтвердить», свободное время |
| Ожидание | `--warning` | `#d97706` | «На рассмотрении», предупреждения |
| Ошибка / опасное действие | `--danger` | `#dc2626` | «Отклонено», «Отменить», ошибки полей |
| Занятие по расписанию | `--class-bg` / `--class-text` | `#e0e7ff` / `#3730a3` | блоки занятий в календаре |

Цвет статуса никогда не единственный носитель смысла: у каждого значка есть текст статуса.

### Типографика и отступы

- Шрифт: системный — Segoe UI / Roboto / Arial; базовый размер 14 px.
- Заголовок страницы — 22 px, жирный; заголовок карточки — 16 px, полужирный; подписи — 12 px.
- Скругление карточек и окон — 10–12 px, полей и кнопок — 8 px.
- Внутренний отступ карточки — 20 px, расстояние между карточками — 16–20 px.

## 2. Каркас страницы

| Компонент | Класс | Описание |
|---|---|---|
| Шапка | `.header` | Логотип, вкладки разделов (`.nav`), колокольчик (`.bell`), пользователь (`.user`), «Выйти». Состав вкладок зависит от роли. |
| Вкладки разделов | `.nav a`, `.active` | Активный раздел подчёркнут и выделен основным цветом. |
| Колокольчик | `.bell`, `.count` | Красный счётчик непрочитанных уведомлений; без непрочитанных счётчик скрыт. |
| Пользователь | `.user`, `.avatar` | Инициалы, ФИО и роль — пользователь всегда видит, под какой ролью работает. |
| Область контента | `.page` | Ширина до 1200 px по центру; заголовок `.page-title` + пояснение `.page-subtitle`. |
| Две колонки | `.row`, `.sidebar`, `.col` | Слева фильтры / вспомогательная панель (280 px), справа основной контент. |
| Панель действий | `.toolbar` | Строка над списком: фильтры слева, главная кнопка справа. |

## 3. Элементы управления

### Кнопки

| Вид | Класс | Когда используется |
|---|---|---|
| Основная | `.btn-primary` | Главное действие экрана: «Найти», «Забронировать», «Сохранить». Одна на экран / окно. |
| Вторичная | `.btn-secondary` | «Отмена», «Календарь», «Перенести», навигация по неделям. |
| Подтверждение | `.btn-success` | «Подтвердить» заявку (диспетчер). |
| Опасная (контур) | `.btn-danger` | Открывает подтверждение опасного действия: «Отменить», «Отклонить». |
| Опасная (заливка) | `.btn-danger-solid` | Финальное подтверждение в модальном окне: «Отменить бронирование», «Отклонить заявку». |
| Размеры | `.btn-sm`, `.btn-block` | Маленькая — в строках таблиц и карточках; на всю ширину — в формах боковой панели. |

### Поля формы

| Компонент | Класс | Описание |
|---|---|---|
| Поле | `.field` + `label` | Подпись над полем; обязательные поля помечены `*`. |
| Ввод / список / текст | `.input`, `.select`, `.textarea` | Единый стиль для `input`, `select`, `textarea`; типы `date`, `time`, `number` — нативные. |
| Подсказка | `.hint` | Серый текст под полем: ограничения («Не больше вместимости — 30»). |
| Ошибка поля | `.input.invalid` + `.error-text` | Красная рамка и текст ошибки под полем (NFR-15). |
| Поля в строку | `.field-row` | «С» / «До», «Корпус» / «Номер». |
| Флажки | `.checks` | Оборудование в фильтре поиска и в карточке аудитории. |

### Вкладки-фильтры

`.tabs` — «таблетки» для переключения вида внутри экрана: фильтр статусов в «Моих бронированиях» (со счётчиком `.num`), «День / Неделя» в календаре, сортировка в очереди заявок.

## 4. Отображение данных

### Значки статусов бронирования

| Статус | Класс | Вид |
|---|---|---|
| На рассмотрении | `.badge-pending` | жёлтый |
| Подтверждено | `.badge-confirmed` | зелёный |
| Отклонено | `.badge-rejected` | красный (под значком — причина) |
| Отменено | `.badge-cancelled` | серый (под значком — кем отменено) |
| Завершено | `.badge-done` | синий |

Тот же компонент показывает доступность аудитории в справочнике: «Доступна» (зелёный), «Закрыта» (серый).

### Прочие компоненты

| Компонент | Класс | Описание |
|---|---|---|
| Метка | `.tag` | Оборудование аудитории, параметры поиска. |
| Карточка | `.card`, `.card-title` | Белый блок с рамкой и тенью — основа всех панелей. |
| Карточка аудитории | `.room` | Номер, корпус, вместимость, оборудование, свободное окно, кнопки «Забронировать» и «Календарь». |
| Таблица | `.table`, `.muted`, `.actions` | Списки бронирований, заявок, аудиторий; вторая строка ячейки — серая; кнопки действий прижаты вправо. На телефоне каждая строка превращается в карточку. |
| Сообщение | `.alert-info / -success / -warning / -danger` | Пояснения и результаты действий. |
| Сводка | `.summary` | Блок «Аудитория / Дата / Время» в начале модальных окон — пользователь видит, с чем работает. |
| Пустой результат | `.empty` | Текст и подсказка, когда список пуст. |

### Календарь занятости

| Элемент | Класс | Описание |
|---|---|---|
| Сетка | `.calendar` | 6 дней (пн–сб) × часы работы корпуса; шаг сетки — 1 час. |
| Заголовок дня | `.cal-head`, `.today` | День недели и дата; сегодняшний — основным цветом. |
| Занятие | `.event-class` | Лиловый блок: дисциплина, время, группа. Нельзя выбрать. |
| Бронирование | `.event-booking` | Зелёный блок: цель и автор. |
| Заявка на рассмотрении | `.event-pending` | Жёлтый блок с пунктирной границей — видят только диспетчер и автор. |
| Выбранный слот | `.event-selected` | Синий блок — то, что пользователь собирается забронировать. |
| Легенда | `.legend` | Расшифровка цветов под календарём. |

Высота блока пропорциональна длительности, верхний край — времени начала.

### Уведомление

`.notif` — иконка-кружок (`.ok` зелёная ✓, `.no` красная ✕, `.info` серая !), заголовок, текст с причиной, ссылка на действие и время. Непрочитанные (`.unread`) подсвечены слева.

### Импорт расписания

| Элемент | Класс | Описание |
|---|---|---|
| Шаги мастера | `.steps`, `.step.done`, `.step.current` | Файл → Проверка → Конфликты → Готово. |
| Зона загрузки | `.dropzone` | Перетаскивание файла или выбор на компьютере. |
| Итоговые числа | `.stats`, `.stat.ok / .bad / .warn` | Загружено / ошибки / конфликты. |

## 5. Модальное окно

`.modal` > `.modal-box` > `.modal-head` / `.modal-body` / `.modal-foot`.

- Открывается поверх экрана и затемняет его; закрывается «×», «Отмена» или Esc.
- В подвале справа — основное действие, слева от него — «Отмена».
- В прототипе окна открываются без JavaScript — по якорю в адресе (`room.html#booking-form`), это позволяет показать любое состояние ссылкой.

Список окон: Э-01а ошибка входа, Э-04 бронирование (+ а/б/в/г), Э-05а отмена, Э-05б перенос, Э-07а отклонение, Э-07б конфликт при подтверждении, Э-08а аудитория, Э-08б корпус, Э-09а отмена брони диспетчером.

## 6. Адаптивность (NFR-14)

При ширине экрана ≤ 760 px:
- вкладки разделов из шапки скрываются (в реализации — меню-«бургер»), имя пользователя сворачивается до инициалов;
- две колонки становятся одной: фильтры над результатами;
- карточки аудиторий — в один столбец;
- таблицы превращаются в стопку карточек;
- календарь прокручивается по горизонтали.
